# Noban — تبدیل گروهی DXF به PDF

انتخاب چند فایل DXF، نمایش هر قطعه و ابعاد واقعی آن در جدول PDF با قالب مشابه نمونه «Part Info». خروجی A4 عمودی، هر صفحه حداکثر ۷ قطعه؛ برای ۱۰ فایل به‌صورت خودکار دو صفحه ساخته می‌شود. تصویرها برداری هستند و نسبت طول به عرض حفظ می‌شود.

## استفاده

1. برنامه را باز کنید و `Add DXF files` را بزنید. چند فایل را هم‌زمان انتخاب کنید.
2. با دوبار کلیک روی هر ردیف، تعداد موردنیاز، تعداد چیدمان و تعداد پردازش‌شده را تنظیم کنید.
   ستون `Check` با یک کلیک یا کلید فاصله تیک می‌خورد. تیک هر قطعه در PDF هم نمایش داده می‌شود؛ کادرهای PDF در نمایشگرهای دارای پشتیبانی فرم قابل تغییر هستند.
3. با `Save PDF` گزارش را ذخیره کنید.

تعداد اولیه از `q2`، `q4` و پسوندهای مشابه نام فایل استخراج می‌شود؛ در نبود آن مقدار ۱ است. تعداد چیدمان و پردازش‌شده ابتدا صفر است. باقی‌مانده برابر تعداد موردنیاز منهای تعداد چیدمان است. نرم‌افزار چیدمان روی ورق یا وضعیت دستگاه برش را محاسبه نمی‌کند.

ابعاد از هندسه واقعی فایل استخراج و با توجه به واحد DXF به میلی‌متر تبدیل می‌شود؛ در فایل بدون واحد، میلی‌متر فرض می‌شود و هشدار نمایش داده می‌شود. نوشته‌ها و اندازه‌گذاری‌های ترسیم از محاسبه ابعاد کنار گذاشته می‌شوند. هر فایل یک قطعه محسوب می‌شود؛ فایل حاوی چند قطعه مستقل ابتدا باید تفکیک شود. هندسه نامعتبر یا پشتیبانی‌نشده با پیام خطا رد می‌شود.

## نصب آفلاین — گزینه پیشنهادی برای کاربران

فایل `Noban-Offline-Setup.exe` شامل نصب‌کننده پایتون، برنامه و تمام کتابخانه‌های ویندوز ۶۴ بیتی است. فقط همین فایل را به سیستم مقصد منتقل و اجرا کنید؛ نصب هیچ دانلودی انجام نمی‌دهد و نیازی به نصب قبلی پایتون ندارد. برنامه در حساب فعلی نصب می‌شود و میان‌بر دسکتاپ و Start ساخته می‌شود. گزارش خطا در `%TEMP%\Noban-install.log` است. این فایل در لینوکس بسته‌بندی شده و نصب واقعی روی ویندوز هنوز آزمایش نشده است.

برای پیدا کردن مسیر واقعی میان‌بر، `Win + R` و سپس `shell:desktop` را بزنید؛ فایل `Noban.lnk` در این پوشه ساخته می‌شود، حتی اگر دسکتاپ به OneDrive منتقل شده باشد. مسیر معمول `%USERPROFILE%\Desktop\Noban.lnk` است. نسخه Start در `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Noban.lnk` قرار دارد. فایل‌های برنامه در `%LOCALAPPDATA%\Programs\Noban` هستند. برای به‌روزرسانی، برنامه را ببندید و نصب‌کننده جدید را دوباره اجرا کنید.

برای بازسازی: وابستگی‌های Windows CPython 3.12 x64 را داخل `offline-assets/wheels` و نصب‌کننده رسمی `python-3.12.10-amd64.exe` را داخل `offline-assets` بگذارید؛ سپس `python make-installer.py --offline` و `makensis offline-installer.nsi` را اجرا کنید. نسخه پوشه‌ای نیز با اجرای `Install-Noban-Offline.cmd` کنار پوشه کامل `offline-assets` نصب می‌شود.

## نصب آنلاین روی سیستم بدون پایتون

فایل `Install-Noban.cmd` را روی ویندوز ۱۰ یا ۱۱ نسخه ۶۴ بیتی دوبار کلیک کنید. نصب اولیه به اینترنت و دسترسی به python.org و pypi.org نیاز دارد. پایتون رسمی با بررسی امضای دیجیتال دریافت می‌شود و وابستگی‌ها خودکار نصب می‌شوند. میان‌بر Noban روی دسکتاپ و منوی Start ایجاد و برنامه اجرا می‌شود. نصب به دسترسی مدیر نیاز ندارد. گزارش خطا در `%TEMP%\Noban-install.log` ذخیره می‌شود. این نصب‌کننده آنلاین است؛ فایل EXE آفلاین نیست و اجرای آن روی ویندوز هنوز آزمایش نشده است.

برای بازتولید این فایل پس از تغییر سورس، `python make-installer.py` را اجرا کنید.

## ساخت نسخه ویندوز آفلاین

روی ویندوز، Python نسخه 3.12 یا جدیدتر را همراه Python Launcher و Tcl/Tk نصب کنید. برای ساخت نصاب، Inno Setup 6 هم لازم است.

فایل `build-windows.cmd` را اجرا کنید. ساخت اولیه به اینترنت نیاز دارد. فایل مستقل `dist/Noban.exe` تولید می‌شود؛ در صورت وجود Inno Setup، نصاب `dist/Noban-Setup.exe` هم ساخته می‌شود. کاربر نهایی فایل نصاب نیازی به نصب پایتون ندارد. نصب برای حساب فعلی ویندوز است و میان‌بر دسکتاپ و امکان حذف برنامه دارد.

**وضعیت تحویل:** PDF نمونه با شش DXF واقعی در لینوکس تولید و بررسی شده است. نصاب آفلاین NSIS شامل پایتون و وابستگی‌هاست؛ نسخه مستقل ساخته‌شده با PyInstaller مسیر ساخت جداگانه دارد. نصب‌کننده‌ها و رابط گرافیکی هنوز روی ویندوز آزمایش نشده‌اند.

## اجرای سورس

```sh
python -m pip install -r requirements.txt
python app.py
```

برای خروجی بدون رابط گرافیکی:

```sh
python app.py part1.dxf part2.dxf -o report.pdf
python -m unittest -v
```

رابط و عنوان ستون‌ها مثل نمونه انگلیسی است. نام فایل فارسی در PDF این نسخه پشتیبانی نمی‌شود؛ برای گزارش از نام فایل لاتین استفاده کنید.
